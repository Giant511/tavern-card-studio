注册策略

—

决定客户端是否显示「注册新账户」，以及谁能自助注册。 保存后立即生效，不需要重启后台服务。

⚠ 已开放自助注册
  • 任何能访问到这个 API 地址的人都可以自行创建账户，不需要审核；
  • 服务端按账户隔离数据，但开放注册等于把「谁能进来」交给网络边界—— 只在内网、或配合邀请制/代理层白名单时使用；
  • 若 API 监听非回环地址（当前 —）， 启动日志与配置检查都会给出同一条安全警告，那是同一个判据。
