## 1. 安卓端是干什么的（与桌面端的分工）

**安卓端不是桌面端的缩小版。** 它把"写卡"这件事留给了桌面端，自己专注做
**读、聊、同步**：

| 能力 | 桌面端 | 安卓端 v0.1.7 |
|---|---|---|
| 八板块完整编辑 | ✅ | ❌（v0.2 候选） |
| 审计面板 / 平台规则校验 | ✅ | ❌（v0.2 候选） |
| 导入本地 TXT / JSON 卡 | ✅ | ❌ |
| 导出 / 另存为 | ✅ | ❌ |
| **与角色聊天** | 走 ST 界面 | ✅ 自研聊天页 |
| **语音输入** | ❌ | ✅ 三种语气档位 |
| **改开场白 / 场景 / 对话示例** | ✅ | ✅「开场与示例」页（只这三项） |
| **从仓库下载卡** | ✅ | ✅ |
| **账号登录 / 同步** | ✅ | ✅ |

一句话：**卡在桌面上写，在手机上看和聊。**

两端共用同一套服务端、同一批账户、同一套版本体系 —— 手机上不需要单独注册。

> 为什么不做编辑器：手机屏幕再大也放不下"八板块 + 审计 + 预览"三栏并排。
> 硬塞进去的结果是一个谁都看不清的界面。v0.1.7 的选择是不做，而不是做个残的。

## 2. 安装

### 2.1 系统要求

| 项 | 要求 |
|---|---|
| Android 版本 | **7.0（API 24）及以上** |
| CPU 架构 | **arm64-v8a**（2015 年之后的正规手机都是） |
| 存储空间 | 安装包 159 MB + 首启解包约 400 MB，**建议预留 1 GB** |

> **32 位老机型（armeabi-v7a）装不上**，因为内置的 Node.js 运行时只有 arm64 版本。
> 这与"我们偷懒"无关 —— 后端要跑一个完整的 SillyTavern，那个运行时必须是真的
> arm64 二进制。国内在售手机 99% 以上是 arm64，实际影响很小。

### 2.2 安装步骤

Android 不允许直接装商店外的包，所以第一次要手动放行：

1. 把 `tavern-card-studio-0.1.7-arm64-release.apk` 传到手机
   （微信/QQ/数据线/U 盘都行）
2. 在文件管理器里点它
3. 系统会拦一次，提示「未知来源应用」→ 点**设置** → 允许该来源安装 → 返回继续
4. 装完点「打开」

### 2.3 如果提示「应用未安装」/「签名冲突」

这只会在**装过旧版**时发生。原因是新旧包签名不同（开发期用过 debug 签名）。

处理办法：**先卸载旧版再装新版**。

> ⚠️ 卸载会连带删掉 App 数据（角色卡、聊天记录、配置都在里面）。
> 如果旧版里有你在意的聊天记录，**先从旧版仓库页上传到服务端**，装好新版再下回来。
>
> 从 v0.1.7 正式版往后的升级不会再有这个问题（同一把签名）。

### 2.4 权限

App 只会申请两个权限，都是功能必需的：

| 权限 | 用在哪 | 不给会怎样 |
|---|---|---|
| 麦克风 | 语音输入 | 点麦克风提示无权限，文字聊天照常 |
| 网络 | 连仓库、连大模型 API | 只能用本地已有卡，不能聊天 |

**没有**通讯录、定位、相册、后台读取之类。语音不录音到本地文件 —— 录完直接
发给识别服务，内存里那份用完就释放。

## 3. 首次启动：它会先解包一个 SillyTavern

这一点必须先说清楚，否则你会以为"卡住了"。

### 3.1 为什么这么慢

安卓端**内置了一整套 SillyTavern 1.19 后端**（含 Node.js 运行时）。首次启动要把它
从 APK 里解出来：

```text
首次启动    解包约 400 MB → 起 Node → 起 ST 服务 → 打开界面     约 60~90 秒
之后每次    直接起服务                                      约 10~20 秒
```

启动画面会显示**当前进度百分比和阶段**（`正在解包…` / `正在启动服务…`），
不是那种转圈不知道在等什么的界面。

> **为什么不在首启联网下载？**
> 那样首次使用要多下 400 MB，手机流量、弱网、切后台中断全是流失点。
> 一次装完、之后永远离线可用，比"装个小包然后等下载"体验好得多。

### 3.2 不要在解包中途杀进程

解包有没有完成是靠**标记文件 + 关键文件都在**双判据确认的。中途被杀掉，
下次启动会**重新解包**（不会留下半个坏环境），但你要再等一遍。

### 3.3 内置测试卡已经不放了

早期版本会在首启往角色目录里放一张「测试用-夜航小助手」供验证用。
**v0.1.7 正式版已经删掉这个行为**，一张测试卡都不放。

已经装过早期版本的手机，升级后首启会**自动清理**掉那张卡，
并给一句提示：「已清理内置测试卡「夜航小助手」。它是早期版本的验证素材，不是你的数据。」

清理用的是**双判据**（文件名前缀 `测试用-` **且** 卡内 `character_version = test-asset`），
两条都命中才删。你自己建的同名卡、别人分享的卡都不会被误删。

## 4. 四个页面总览

底部四个 Tab，右下角永远是你的当前位置：

| Tab | 干什么 |
|---|---|
| 💬 **聊天** | 选角色、聊天、语音输入。**日常 90% 时间在这里** |
| 🗂 **卡片** | 本地有哪些角色；改开场白 / 场景 / 对话示例 |
| ☁️ **仓库** | 登录账号、从服务端下载卡、看历史版本 |
| ⚙️ **我的** | 配大模型 API、配语音识别、聊天参数 |

页面之间是**层叠转场**：进去新页面从右侧推入，返回时滑出。系统返回手势
（左/右边缘内滑）与左上角返回按钮走同一套逻辑。

## 5. 聊天页

### 5.1 顶栏

从左到右：

| 位置 | 元素 | 作用 |
|---|---|---|
| 左 | ☰ | **选择角色**。点开是角色列表，选一个才开始聊天 |
| 中 | 副标题 | 显示当前角色名；没选时是「未选择聊天」 |
| 中 | 👤 人设 ▾ | **切换「你自己」是谁**（人设胶囊）。点开是下拉列表 |
| 右 | ⚙ | 聊天设置（温度、回复长度、上下文条数…见 §11） |

**人设胶囊**值得单独说：它决定 `{{user}}` 在提示词里被替换成什么。
下拉里选「默认人设」就是用角色卡自带的称呼；选了具体人设，
那个人的名字、设定会一起进上下文。**换人设不需要重新开始对话**。

### 5.2 消息区

- 消息气泡按你说的、角色说的分左右
- **点气泡 → 进入编辑**，可以改这条消息的内容
- **长按气泡 → 复制 / 删除**
- 角色回复下方有 ↻ **重新生成**，会替换掉这一条
- 向上滚动会自动加载更早的记录

### 5.3 输入区

| 元素 | 说明 |
|---|---|
| 输入框 | 多行，回车换行。中文输入法正常 |
| `"` `（）` `「」` | **快捷键盘**：一下插入一对符号，光标停在中间 |
| ↻ | 重新生成上一条回复 |
| 🎤 | 麦克风。**点一下进入语音态**（见 §6） |
| ↑ | 发送 |

输入框有内容时发送键才亮；空内容发不出去（不会发一条空气泡）。

### 5.4 聊天记录会自己存

每轮对话后自动保存，切 Tab、切角色、杀进程都不会丢。
换角色再换回来，记录还在。

## 6. 语音输入

### 6.1 两个动作，不是三个

```text
① 点麦克风         → 进入语音态（输入区变成键盘图标 + 一个大圆麦克风）
② 按住大圆说话     → 说话时实时显示波形与秒数
③ 松手             → 立刻释放麦克风，开始转写
```

**松手就释放**，不等后台、不等转写结果。这是刻意的：麦克风被占着的那几百毫秒里，
如果来电话，系统会打断录音并且可能不给通知 —— 提前释放就没有这个问题。

### 6.2 三种档位（左右滑选）

按住大圆后，**手指左右滑动**切换档位，三个圆从左到右：

| 档位 | 输出样子 | 用在哪 |
|---|---|---|
| **说话** | `"你说的话"` | 角色扮演里"我"开口（默认档位） |
| **内心/动作** | `(心里想 / 做的动作)` | 旁白、动作描写、心里想 |
| **消息** | `「像发一条微信那样」` | 引用一段消息 |

选中的圆会高亮，松手时按**当时选中的档位**加符号。

> 为什么不让 AI 猜你要哪种：语音是高频小动作，任何"猜错了"都会立刻让人烦躁，
> 而且没法申诉。本地拼符号是零延迟、零成本、结果完全确定的。

### 6.3 上滑取消

按住后**手指上滑**，进入取消态（两个档位圆一起变暗、提示变成「松开取消」），
松手即放弃这次录音，什么都不发。

想反悔：上滑到取消态后**手指滑回来**，取消态解除，可以继续说话。

### 6.4 转写完之后

- **默认直接发出去** —— 你说完就想发，多一次确认是多余动作
- 想改成"先给我看一眼再发"：在「我的 → 语音输入配置」里打开
  **发送前确认**，之后转写结果会变成一张**草稿卡**：可以直接改，改完点发送；
  或者点 ✕ 丢掉

### 6.5 转写失败时

不会静默失败。会明确告出是哪一类问题：

| 提示 | 真实原因 | 怎么办 |
|---|---|---|
| 未配置语音识别 | 没填 key | 去「我的 → 语音输入配置」配一个 |
| 密钥无效或余额不足 | key 错了 / 欠费 | 换 key 或充值 |
| 网络不可达 | 服务地址连不上 | 检查地址、代理；国内建议用阿里百炼 |
| 录音权限被拒 | 系统层面拒绝了麦克风 | 系统设置里给权限 |
| 没有听到声音 | 录到的全是静音 | 检查麦克风是否被别的 App 占着 |

## 7. 卡片页：开场与示例

这是安卓端**唯一能改卡片内容**的地方，v0.1.7 新增。

### 7.1 能改什么

进去先选角色，然后是三段输入框：

| 字段 | 对应 ST 字段 | 作用 |
|---|---|---|
| **场景** | `scenario` | 故事发生在哪、此刻什么状况。**每轮对话都会发给模型** |
| **开场白** | `first_mes` | 新对话的第一条消息 |
| **备用开场白** | `alternate_greetings[]` | 多个开局，聊天时可以左右滑选 |

> 为什么只给这三项：这三项最常需要"随手改一下"（换个开场、调整场景），
> 而它们改坏了也容易看出来。性格、世界观这些结构性内容改坏了，
> 在手机上看不出后果 —— 那种改动应该回桌面端做。

### 7.2 场景必须与开场白一致

这是最常见的隐形错误：

```text
场景     "旧城区下着小雨，{{user}}推门走进「拾光」书店"    ← 每轮都在发
开场白   "夜里十点半，私人健身工作室…"                     ← 聊天从这里开始
```

两句话来自两张不同的设定。模型每轮看到的是"书店"，而对话发生在"健身房" ——
表现就是「AI 老是把场景搞错」，但改提示词怎么改都没用。

在同一屏里这两段挨着，**一眼就能看出矛盾**。这是把它们放一起的主要理由。

### 7.3 保存

改完点保存。保存会写回角色卡（PNG 里的卡数据），**下次聊天立刻生效**。

没保存就退出会问一句，不会静默丢弃。

## 8. 仓库页：账号、下载、历史

### 8.1 两种仓库

| 类型 | 地址 | 说明 |
|---|---|---|
| **内置云仓库** | `ai.gezblog.xyz:8730` | 强制 HTTPS，不可降级。**需要邀请码才能注册**，找开发者要 |
| **自定义仓库** | 你自己填 | 自部署的同一套服务端。填 HTTP 地址时会先弹风险确认 |

> 内置云仓库那条「需邀请码」的提示是刻意常驻的 —— 不这样的话，用户会一直
> 以为是"注册按钮坏了"，而不是"这里需要一个码"。

### 8.2 登录

支持两种凭证，**互斥**（用了一个会退出另一个）：

- **账户登录**：用户名 + 密码。能管自己的全部仓库、全部卡
- **仓库令牌**（`tcr_…`）：只对**一个仓库**有权限，可分别授予读 / 写 / 回滚。
  适合把令牌给别的设备或脚本用，不暴露密码

令牌模式下仓库选择器会隐藏（只有一个仓库），按钮按权限置灰。

### 8.3 三级结构

```text
仓库列表  →  某个仓库里的卡片  →  某张卡的历史版本
   ↑              ↑                    ↑
  登录后          点一张卡              点「历史」
```

返回时逐级退回（系统手势与左上角按钮同一套）。

### 8.4 下载卡片

在某张卡上点下载，会落到本地角色目录，**回卡片页就能看到**。

- 同名卡**覆盖更新**，不产生副本 —— 服务端那张是权威版本
- 下载完有明确状态：`下载中…` → `已下载 ✓`（失败则显示可点的「重试」）
- 卡片自带的世界书会一起落地（写进 ST 的 `worlds/` 目录并挂到卡上）

### 8.5 连通性指示灯

仓库页顶部有一个状态灯，它同时表达两件事：

| 灯 | 文字 | 含义 |
|---|---|---|
| 🟢 | 已登录 | 连通且已登录，可以正常用 |
| 🟢 | 未登录 | 服务端通着，但还没登录（**这是最常见状态**） |
| 🔴 | 连不上 | 地址不通 / 服务没起 / 证书被拒 |

> 注意 **HTTP 401 也算"在线"** —— 未登录本来就该 401，那是服务器在正常回应。
> 只有真正连不上才算红灯。

## 9. 我的页：API 连接

聊天要用大模型，这里配。

### 9.1 配置结构

```text
我的 → API 连接（点开展开）
        ├─ 选服务商预设（OpenAI / Groq / Claude / 自定义…）
        ├─ 服务地址（baseUrl）
        ├─ API Key
        ├─ 模型名（可点「获取模型列表」自动拉）
        └─ 保存
```

### 9.2 常见服务商

| 服务商 | 地址 | 备注 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | 需外币卡 |
| **阿里百炼** | `https://dashscope.aliyuncs.com/compatible-mode/v1` | **国内直连**，中文好 |
| DeepSeek | `https://api.deepseek.com/v1` | 国内直连，便宜 |
| Groq | `https://api.groq.com/openai/v1` | 快，需海外网络 |
| 自建 / 中转 | 你填 | 兼容 OpenAI 协议的都行 |

### 9.3 保存后怎么看生效了

- 上方的收纳行会变成 **「API 连接 当前：<服务商>」**
- 保存时按钮上会显示 **「已保存 ✓」**（不是只弹一句飘过去就算）
- 保存**不会**清空你填的地址与 key，也不会把滚动位置跳回顶部

### 9.4 关于 Key 的存储

Key 存在手机本机（App 私有目录），**不上传到仓库**。
界面上只显示一串星号，不会再把原文显示出来。

> 换手机、重装 App 都要重填 —— 这是刻意的：key 跟着仓库走等于多一条泄露路径。

## 10. 我的页：语音输入配置

### 10.1 五个内置预设

| 预设 | 特点 | 备注 |
|---|---|---|
| **阿里百炼 · 语音识别** | 国内直连、中文最强 | **推荐**，无需翻墙 |
| Groq | 免费额度大、快 | 需海外网络 |
| OpenAI | 稳定 | 需海外网络与外币付费 |
| 本地 whisper.cpp | 隐私优先 | 需自建服务 |
| Gemini（高级） | 多模态 | 海外 |

### 10.2 配置步骤

1. 「我的 → 语音输入配置」点开
2. 选一个预设
3. 填 Key（有 `baseUrl` 的也可改地址）
4. 点 **「测试连接」** —— 它会真的发一次识别请求
5. 通过后点「保存」

### 10.3 「测试连接」返回什么

| 结果 | 含义 |
|---|---|
| 连接正常 | key、地址、模型全对，可以用 |
| 密钥无效或余额不足 | key 错 / 欠费 / 服务端拒绝 |
| 未配置 key | 没填 |
| 网络不可达 | 地址连不上（含证书问题） |

> 这条**会真的调一次接口**（可能产生极小费用）。它比"看起来存上了"重要得多 ——
> 一个只写进配置、实际调不通的 key，会让你在真正说话时才发现问题。

## 11. 聊天设置

聊天页右上角 ⚙ 进入，一页 12 项，分四组：

### 11.1 采样参数

| 项 | 作用 | 建议 |
|---|---|---|
| **温度** | 越高越发散 | 角色扮演 0.8~1.0 |
| **Top P** | 采样范围 | 0.9~1.0 |
| **最大回复长度** | 单条上限 | 300~800 token |
| **频率惩罚 / 存在惩罚** | 抑制重复 | 一般 0~0.3 |

### 11.2 上下文

| 项 | 作用 |
|---|---|
| **上下文上限** | 一次请求最多带多少 token |
| **回复预留** | 从上限里划给模型写回复的部分 |
| **历史条数** | 最多带几轮对话 |

> **预算不够时会发生什么**：优先丢掉**对话示例**（`mes_example`），
> **保住聊天历史**。理由很直接 —— 示例示范的是"角色怎么说话"，丢了只是语气淡一点；
> 历史丢了角色立刻失忆。这与 SillyTavern 自己的选择一致。

### 11.3 提示词

| 项 | 作用 |
|---|---|
| **思考链显示** | 打开后能看到模型的推理过程（DeepSeek 等支持） |
| **思考长度** | 限制推理长度，太长会拖慢回复 |

### 11.4 行为

| 项 | 作用 |
|---|---|
| **发送后自动滚动** | 新消息自动滚到底 |
| **人设位置** | 你的设定放在提示词的哪个位置 |
| **作者注释** | 每 N 轮插一次的背景提示 |

> 设置项里凡是标注「ST 独有」的，都是 SillyTavern 那边才生效的参数。
> 标出来是为了避免"我改了怎么没反应" —— 不是我们没实现，是那个参数
> 只在 ST 自己的界面里起作用。

## 12. 数据存在哪、怎么备份

### 12.1 位置

Android 的 App 私有目录，**不 root 看不到**：

```text
/data/data/com.taverncardstudio.client/files/
└── st-data/
    └── default-user/
        ├── characters/     ← 角色卡（PNG）
        ├── chats/          ← 聊天记录（.jsonl）
        ├── worlds/         ← 世界书
        └── ...             ← ST 的其它数据
```

### 12.2 备份的三条路

| 方式 | 覆盖范围 | 怎么做 |
|---|---|---|
| **上传到仓库** | 角色卡（含卡面） | 仓库页 → 上传。**最推荐**，跨设备可用 |
| **聊天记录** | 只有聊天 | 目前没有导出入口，只能整机备份 |
| **整机备份** | 全部 | Android 自带的备份工具 / 换机助手 |

> 聊天记录目前**没有导出入口**。要保留就上传角色卡（设定不丢），
> 或者用系统级换机工具整机搬。

### 12.3 卸载会删什么

卸载 App = **删掉上面整个目录**（角色卡、聊天记录、配置全没）。

**卸载前请先把卡上传到仓库。** 系统不会二次确认这件事。

## 13. 常见问题

### 13.1 启动一直停在解包

首次解包 60~90 秒是正常的，看进度百分比有没有在动：

- **在动** → 等着
- **长时间不动** → 可能磁盘满了。清理出 1 GB 再重启 App

### 13.2 点角色没反应

正常情况应该**立即跳转**，卡片内容后台慢慢加载。如果点了完全没反应，
说明角色列表渲染出问题了 —— 杀掉 App 重开。

### 13.3 聊天报错「未配置 API」

去「我的 → API 连接」配一个（见 §9）。配完不用重启 App。

### 13.4 语音说了没反应

按顺序排查：

1. 麦克风权限给了吗（系统设置 → 应用 → 权限）
2. 「我的 → 语音输入配置」里点「测试连接」通不通
3. 手机是不是静音/被别的 App 占着麦克风（微信语音通话中会占用）

### 13.5 仓库连不上

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示证书错误 | 自建仓库用了自签证书 | 用 HTTPS 正式证书，或先在浏览器里信任一次 |
| 提示网络不可达（很快就失败） | 地址写错 / 端口没开 | 用浏览器试一下那个地址 |
| 提示网络不可达（等很久才失败） | 真的连不上（防火墙 / 网络） | 换网络试试 |
| 灯是绿的但下载 401 | 未登录 | 先登录 |

> **判断技巧**：失败得**很快**（几百毫秒）通常是客户端问题（地址错、证书拒）；
> 失败得**很慢**（十几秒）才是网络问题。

### 13.6 下载的卡看不到世界书

世界书落在 `worlds/` 目录，并且会挂到卡上。如果角色能用但世界书不触发，
去 SillyTavern 的界面里确认一下「世界书」有没有选中 —— 这一步目前要在
ST 界面里做，安卓端不代劳。

### 13.7 角色列表里有个「测试用-夜航小助手」

说明你的手机装过 v0.1.7 早期版本。升级到正式版后首启会**自动删掉**。
如果没删（比如你没升级），手动删也行。

## 14. 已知限制

这些是**明确不做**或**暂时做不到**的，不是 bug：

### 14.1 只支持 arm64

32 位老机型（armeabi-v7a）和 x86 设备（模拟器、云手机、极少数 Chromebook）
装不上。原因见 §2.1。

> **云手机用户注意**：多数云手机跑在 x86 服务器上，装不了这个包。

### 14.2 不做卡片编辑器

见 §1 的分工表。手机只改「场景 / 开场白 / 备用开场白」三项。

### 14.3 不做 TXT 导入 / 导出

安卓端从仓库下载卡，不从文件系统导入。要看 TXT 请用桌面端。

### 14.4 不做审计

平台规则校验、字数分布、问题定位都在桌面端。

### 14.5 自签证书需要先信任

自建仓库如果用的是自签证书（`selfsigned` 模式），安卓端会拒绝连接 ——
系统的网络安全策略不允许 App 直接信任未知证书。

三条出路：
1. 用正式证书（Let's Encrypt 免费）
2. 用反向代理终止 TLS，仓库地址填代理的域名
3. 换用内置云仓库

> 这一条与桌面端的表现不同：桌面端会提示"证书不受信任"并允许你确认，
> 安卓端目前没有这个确认流程（v0.2 候选）。

### 14.6 聊天记录不能导出

见 §12.2。要长期保留请依赖仓库里的角色卡 + 系统级备份。

### 14.7 语音识别依赖第三方服务

App 不自带语音识别模型（那会让安装包再大几百 MB）。所有识别都调你配的
那个服务，按那边计费。
