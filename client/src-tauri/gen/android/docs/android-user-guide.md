# Tavern Card Studio 安卓端使用手册

适用 v0.1.7。Android 7.0 及以上，arm64 机型。

桌面端的手册在仓库根目录 README，讲的是编辑、审计、推送。这本只讲手机上怎么用。

---

## 这个 App 在手机上做什么

一句话：卡在电脑上写，在手机上看和聊。

手机上不写完整的角色卡。八板块编辑、平台规则审计、TXT/JSON 导入导出，这些都在桌面端。
手机端只改三样东西：场景、开场白、备用开场白。理由很简单，屏幕就那么大，把
"八板块 + 审计 + 预览"三栏并排塞进去，谁看都费劲。

手机端擅长的是另一头：跟角色聊天，用语音说话，从仓库把卡取下来。

| 事情 | 桌面端 | 手机端 |
|---|---|---|
| 八板块完整编辑 | 可以 | 不行 |
| 审计、规则校验 | 可以 | 不行 |
| 导入本地 TXT / JSON | 可以 | 不行 |
| 改场景、开场白、备用开场白 | 可以 | 可以 |
| 跟角色聊天 | 走网页界面 | 手机原生界面 |
| 语音输入 | 没有 | 三档语气 |
| 从仓库下载卡 | 可以 | 可以 |
| 账号登录、同步 | 可以 | 可以 |

两端共用一套服务端和账户。手机上不用另外注册。

## 安装

### 机器要求

Android 7.0 起。CPU 要 arm64-v8a，2015 年以后的正规手机都是。
存储留 1 GB：安装包 159 MB，第一次启动还要解出约 400 MB。

32 位老机型装不上。内置的运行时只有 arm64 版本，这不是省事，是那个运行时
必须是真的 arm64 二进制。国内在卖的手机几乎全是 arm64，实际影响很小。

云手机多半跑在 x86 服务器上，也装不了。

### 装的时候会拦一次

1. 把 `tavern-card-studio-0.1.7-arm64-release.apk` 传到手机
2. 在文件管理器里点它
3. 系统提示"未知来源"，点设置，允许这个来源，返回继续
4. 装完点打开

### 提示"应用未安装"或"签名冲突"

只在装过旧版时出现。v0.1.7 正式版的签名跟早期开发包不同。

先卸载旧版再装。卸载会连同 App 数据一起删掉，角色卡、聊天记录、配置全没。
旧版里有要留的聊天记录，先去旧版的仓库页把卡传上去，装好新版再下回来。

从这一版往后升级不会再有这个问题，签名不会变。

### 只申请两个权限

麦克风用来做语音输入，网络用来连仓库和模型接口。

没有通讯录、定位、相册、后台读取。录音不落文件，转写完内存里那份就丢。

## 第一次启动要等

手机端内置了一整套角色引擎，含 Node.js 运行时。第一次启动要把它从安装包里解出来。

```
第一次   解包约 400 MB → 起引擎 → 进界面    60~90 秒
之后     直接起引擎                        10~20 秒
```

启动画面会显示进度百分比和当前在干什么（"正在解包"、"正在启动"），
不是转个圈让你猜。

解包别中途杀进程。解到一半被杀，下次会从头再来，不会留下半个坏环境。

为什么不做成首启下载：那样第一次用得多下 400 MB，手机流量、弱网、切后台中断，
每个都是流失点。一次装完，之后永远离线可用。

## 四个页面

底部四个格子，右下角那个是你现在的位置。

| 格子 | 干什么 |
|---|---|
| 聊天 | 选角色、聊天、说话。日常九成时间在这 |
| 卡片 | 看本机有哪些角色，改开场和场景 |
| 仓库 | 登录、下载卡、看历史版本 |
| 我的 | 配模型接口、配语音识别、聊天参数 |

页面之间是层叠推拉的。进新页面从右边推进来，返回时滑出去。系统返回手势和
左上角返回按钮走同一套逻辑。

## 聊天页

### 顶栏

左边 ☰ 是选择角色。点开是角色列表，选一个才开始聊天。这里也是你唯一能
看到"本机有哪些角色"的地方。

中间显示当前角色名。没选的时候写"未选择聊天"。

角色名旁边有个 👤 人设胶囊，点开可以换"你是谁"。这个决定提示词里
代表你的那个名字被替换成什么。选了具体人设，那个人的名字和设定会一起进上下文。
换人设不用重开对话。

右边 ⚙ 是聊天设置，见后面。

### 消息

气泡按谁说的分左右。点一下气泡进编辑，长按出复制和删除。
角色回复下面有个 ↻，重新生成，会替换掉这一条。往上滚会自动加载更早的记录。

### 输入区

输入框支持多行，回车换行。旁边三个小键 `"` `（）` `「」` 一下插一对符号，
光标停在中间。

↻ 重新生成上一条。🎤 进语音态。↑ 发送，输入框空的时候发不出去。

### 记录自己存

每轮对话后自动保存。切格子、换角色、杀进程都不会丢。换回来还在。

## 语音输入

### 两步

```
点麦克风      进语音态，输入区变成键盘图标 + 一个大圆麦克风
按住大圆      说话，屏幕上实时显示波形和秒数
松手          立刻释放麦克风，开始转写
```

松手就释放，不等后台也不等转写结果。麦克风被占着的那几百毫秒里要是来电话，
系统会打断录音，而且可能不给你通知。提前释放就没这问题。

### 三个档位

按住之后左右滑，三个圆从左到右：

| 档位 | 输出 | 用在哪 |
|---|---|---|
| 说话 | `"你说的话"` | 角色扮演里你开口。默认 |
| 内心/动作 | `(心里想的、做的动作)` | 旁白、描写、心里话 |
| 消息 | `「像发一条微信」` | 引用一段消息 |

松手时按当前选中的档位加符号。

为什么不让 AI 猜你要哪种：语音是高频小动作，猜错一次就够烦躁，而且没处申诉。
本地拼符号是零延迟、零成本、结果完全确定的。

### 上滑取消

按住后手指上滑，两个档位圆一起变暗，提示变成"松开取消"，松手这次就白说了。
上滑到取消态再滑回来，取消态解除，可以继续说。

### 转写完之后

默认直接发出去。说完就想发，多一次确认是多余的。

想先看一眼再发，去"我的 → 语音输入配置"打开发送前确认。之后转写结果会变成一张
草稿卡，可以直接改，改完点发送，或者点 ✕ 丢掉。

### 失败时告你哪一步坏了

| 提示 | 真实原因 |
|---|---|
| 未配置语音识别 | 没选服务商或没填 key |
| 密钥无效或余额不足 | key 错了、欠费、或者服务端拒绝 |
| 网络不可达 | 地址连不上。分快慢：几百毫秒就失败多半是地址或证书，十几秒才失败是网络 |
| 录音权限被拒 | 系统层面拒绝了麦克风 |
| 没有听到声音 | 录到的全是静音，检查麦克风有没有被别的 App 占着 |

## 卡片页

### 它不能切换聊天角色

这一点最容易误解。卡片页的"选一个角色"，选的是要改哪张卡的开场，
跟聊天用谁没有关系。

要换聊天角色，去聊天页点 ☰。要查看本机有哪些角色，也是在那里看。

### 能改的三样

进去先选一张卡，然后是三段输入框。

| 字段 | 作用 |
|---|---|
| 场景 | 故事发生在哪、此刻什么状况。每轮对话都会发给模型 |
| 开场白 | 新对话的第一条消息 |
| 备用开场白 | 多个开局可选，聊天时能左右滑挑一个 |

只放这三项的理由：这三项最常需要随手改一下（换个开场、调整场景），
而且改坏了一眼能看出来。性格、世界观那种改坏了在手机上看不出后果，
应该回电脑上改。

### 场景和开场白要对得上

这是最常见的隐形错误：

```
场景     "旧城区下着小雨，{{user}}推门走进「拾光」书店"      ← 每轮都在发
开场白   "夜里十点半，私人健身工作室里只剩下你和我"          ← 聊天从这里开始
```

两句话来自两张不同的设定。模型每轮看到的是书店，而对话发生在健身房。
表现就是"AI 老是把场景搞错"，可你去改提示词怎么改都没用。

把这两段放同一屏，就是为了让你一眼看出矛盾。

### 保存

改完点保存，写回角色卡，下次聊天立刻生效。没保存就退出会问一句，不会静默丢弃。

## 仓库页

### 两种仓库

内置云仓库地址是 `ai.gezblog.xyz:8730`，强制 HTTPS，不能降级。要邀请码才能注册，
找开发者要。

自定义仓库填你自己的地址，跑的是同一套服务端。填 HTTP 地址会先弹一次风险确认。

内置仓库那条"需邀请码"的提示是常驻的。不这样的话用户会一直以为注册按钮坏了，
而不是这里需要一个码。

### 登录

两种凭证，用了一个会退出另一个。

账户加密码能管自己全部仓库、全部卡。

仓库令牌（`tcr_…`）只对一个仓库有效，读、写、回滚可以分别授权。
适合给别的设备或脚本用，不用交出密码。令牌模式下仓库选择器会隐藏，
按钮按权限置灰。

### 三级

```
仓库列表  →  某个仓库里的卡  →  某张卡的历史版本
```

返回时逐级退，系统手势和左上角按钮一样。

### 下载

在某张卡上点下载，落到本地角色目录，回卡片页就能看到。

同名卡覆盖更新，不会生出副本，服务端那份是权威版本。下载状态有三种：
下载中…、已下载 ✓、失败了显示重试。

卡自带的世界书会一起落地，挂到卡上。

### 连通状态灯

仓库页顶部有个灯，同时表达两件事。

| 灯 | 文字 | 含义 |
|---|---|---|
| 绿 | 已登录 | 通了，也登录了 |
| 绿 | 未登录 | 服务器通着，但还没登录。这是最常见状态 |
| 红 | 连不上 | 地址不通、服务没起、或者证书被拒 |

HTTP 401 也算在线。未登录本来就该 401，那是服务器在正常回话。
只有真的连不上才是红灯。

## 我的页：模型接口

聊天要用模型，在这里配。

点开"API 连接"能看到：服务商预设、服务地址、API Key、模型名、保存。

### 常见服务商

| 服务商 | 地址 | 备注 |
|---|---|---|
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 国内直连，中文好 |
| DeepSeek | `https://api.deepseek.com/v1` | 国内直连，便宜 |
| OpenAI | `https://api.openai.com/v1` | 要外币卡 |
| Groq | `https://api.groq.com/openai/v1` | 快，要海外网络 |
| 自建或中转 | 你填 | 兼容 OpenAI 协议的都行 |

模型名可以点"获取模型列表"自动拉。

### 怎么看出存上了

上方那行会变成"API 连接 当前：某某服务商"。点保存的时候按钮上会显示"已保存 ✓"，
不是飘一句提示就完事。

保存不会清空你填的地址和 key，也不会把页面滚回顶部。

Key 存在手机本地，不上传仓库，界面上只显示星号。换手机或重装都要重新填。
这是故意的，key 跟着仓库走等于多一条泄露路径。

## 我的页：语音识别

### 八个预设

点开"语音输入配置"，从上到下八个。前六个是常用路线，最后两个标着"高级"。

| 预设 | 需要 key | 模型 | 说明 |
|---|---|---|---|
| 阿里百炼 · 语音识别 | 要 | `qwen3-asr-flash` | 国内直连，中文最强。推荐 |
| Groq | 要 | `whisper-large-v3-turbo` | 免费额度大、快，要海外网络 |
| OpenAI | 要 | `whisper-1` | 稳定，要海外网络和外币付费 |
| 本地 whisper.cpp | 要 | 自填 | 隐私优先，要自建服务 |
| 本地 Fun-ASR（Gradio） | 不要 | `fun-asr-nano` | 自建服务，局域网地址手填 |
| 中转站 / 自定义 | 要 | 你填站里的 ID | 多数中转站兼容 OpenAI 接口 |
| Qwen-Audio ASR（百炼） | 要 | `qwen-audio-3.0-asr-flash` | 高级。抗噪，听得懂语气词 |
| Gemini | 要 | 自填 | 高级。海外 |

国内网络选阿里，有海外网络选 Groq。这是界面上那句快捷建议的原话。

### 几个容易踩的地方

阿里百炼那条不走 OpenAI 的 `/audio/transcriptions`。百炼现在用多模态生成接口
加 `qwen3-asr-flash`。老的 `paraformer-v2` 在新接口里已经查不到，用它会拿到 404，
而 404 的提示是"地址填错了"，跟你看到的文档完全对不上。所以预设里地址已经写死，
别手动改成兼容模式那个。

本地 Fun-ASR 不需要 key，但地址必须手填。它是局域网里的 Gradio 服务，
格式是 `http://192.168.x.x:7860`。填本机 `127.0.0.1` 没用，手机上那个 127 是手机自己。

本地 whisper.cpp 反而要填 key。自建服务多半会要求一个口令，填服务端配的那个。

中转站 / 自定义的模型名要填站里的 ID，不是 `whisper-1`。不同中转站命名不一样，
填错会回"模型不存在"。

### 配置步骤

1. 选一个预设
2. 填 key（预设需要的话），填地址（预设要求的话）
3. 点"测试连接"，它会真的发一次识别请求
4. 通了再点保存

"测试连接"会真调接口，可能产生极小费用。这一步比"看起来存上了"重要得多，
一个只写进配置、实际调不通的 key，会在你真说话的时候才暴露。

### 测试连接会返回什么

| 结果 | 意思 |
|---|---|
| 连接正常 | key、地址、模型全对 |
| 密钥无效或余额不足 | key 错、欠费、或服务端拒绝 |
| 未配置 key | 你没填 |
| 网络不可达 | 地址连不上，含证书问题 |

## 聊天设置

聊天页右上角 ⚙ 进去。分四组。

### 回复长度与采样

最大回复长度（Token）管单条上限，800 左右够用。

采样组里温度最关键，角色扮演 0.8~1.0。其余几项（Top P、Top K、Top A、Min P、
重复惩罚、频率惩罚、存在惩罚、种子）不懂就别动，默认值能正常工作。

### 随机性与回复详略

推理强度是给支持"思考"的模型用的档位：自动、最低、最高。

回复详略里的长度是：自动、简短、适中、详细。它影响的是让模型写多长，
跟上面的"最大回复长度"不是一回事，那个是硬上限。

### 上下文预算

上下文长度（Token）填了才会按预算裁剪。不填就是不裁剪，
长对话迟早会超模型的窗口，然后接口报错。

预算不够的时候会先丢对话示例，保住聊天历史。理由很直白：
示例教的是"这个角色怎么说话"，丢了顶多语气淡一点；历史丢了角色立刻失忆。

作者注释是每几轮插一次的背景提示。CFG 缩放、CFG 反向提示、去掉多余空格、
合并连续空行、去掉不完整句子、快速续写、发送时自动续写，这几项按需开。

### 思考过程

这一组最容易搞混，因为它管的是两件不同的事。

第一件，模型要不要思考、想多久。在"思考过程"这一组的开关上。打开后请求里会多带
厂商规定的字段，模型先想一段再回答。想得越久越慢越费 token，但复杂场景下质量更好。

不同厂商的字段名不一样，有四种：

| 参数族 | 厂商 |
|---|---|
| `thinking.type` | 智能体类、GLM、Kimi、豆包、MiniMax |
| `enable_thinking` | 百炼、硅基流动、vLLM |
| `reasoning_effort` | OpenAI、xAI、阶跃 |
| `think` | Ollama 本地 |

App 会按模型名自动认出是哪一家，认出后按那家的配方注入。认不出就让你手选参数族，
不会瞎猜。前端不猜厂商，这是硬规矩。

有些型号关不掉思考。GLM-5.3 和 4.7 强制思考，Kimi 的 k2.7-code 强制思考，
Gemini 2.5 Pro 和 3/4 系只能调深度不能关，Claude 带 `-thinking` 后缀的也关不掉。
遇到这类型号，开关会显示成不可用并说明原因，而不是让你点了没反应。

思考长度旋钮的含义随厂商变：有的填数值上限（`thinking_budget`），有的选档位
（`reasoning_effort` 的低/中/高）。同一家的不同型号也可能不一样。

第二件，气泡里显不显示想的内容。是"显示完整思考链"这个开关。

打开：模型思考时气泡里会显示完整的思考过程。
关掉：只显示"思考中…"，不显示具体内容。

这个开关只影响显示，不影响请求，也不影响花多少钱。默认关。
手机上屏幕小，完整的思考链经常比回复本身还长。

两个概念分开是有意的：很多人只想让模型好好想，但不想看它想的过程。

### 管理提示词

看这份预设带了哪些提示词，逐条开关。能逐条启停上下文里拼进去的提示词块，
以及调作者注释的插入深度和次序。

## 数据在哪、怎么备份

### 位置

App 私有目录，不 root 看不到。

```
/data/data/com.taverncardstudio.client/files/
└── st-data/
    └── default-user/
        ├── characters/     角色卡
        ├── chats/          聊天记录
        ├── worlds/         世界书
        └── ...
```

### 三条备份路

上传到仓库：只管角色卡，包括卡面。最推荐，换设备也能用。

聊天记录目前没有导出入口，只能靠整机备份。

系统级换机工具能搬全部。

### 卸载会删什么

卸载等于删掉上面整个目录。角色卡、聊天记录、配置全没。

卸载前先把卡传到仓库。系统不会为这件事二次确认。

## 从手机导入卡片

v0.1.8 新增。不联网、不登录仓库，也能把一张卡弄进 App。

### 在哪

「卡片」页最上面那条「从手机导入卡片」，点一下开系统文件选择器。

### 支持什么

| 格式 | 能不能导 | 封面 |
|---|---|---|
| PNG 卡 | 能 | 用这张图自己的封面 |
| JSON 卡 | 能 | 用 App 内置的默认封面 |
| TXT 卡 | 不能 | — |

TXT 不支持是刻意的。桌面端的 TXT 是带板块标记的自有格式（`@@性格` 之类），
不是通用文本。手机上随手导一个 TXT 只会得到空卡 —— 那还不如明确说不行。
TXT 请回桌面客户端导入。

文件扩展名不对也没关系：App 是按**文件内容**判断的，不看名字。
微信转存改了后缀的卡照样能导。

### 同名会问你

导入的卡如果和本地已有的卡**同名**，会先弹一句：

```
本地已有「小明」
覆盖会替换这张卡的内容，不能恢复。
        [覆盖]  [取消]
```

点取消就什么都不动。

这一问是必要的。仓库下载不需要问（那份是权威版本，你点下载就是要把本地刷成它），
但从别人那里收到一张同名卡时，你不一定想让它顶掉自己那张。

### 导进来之后

去聊天页点左上角 ☰，角色列表里就有了。不用杀 App，也不用重启引擎。

它不会自动传到仓库。想同步到别的设备，去「仓库」页手动上传 ——
导入一张私人卡不该被自动分享出去。

### 导不进去的几种提示

| 提示 | 意思 |
|---|---|
| 这张 PNG 里没有卡片数据，只是一张图片 | 选的是插画或截图，不是卡 |
| 这张 PNG 读不出来（…） | 文件损坏或被截断，重新下一份 |
| 「x.json」不是有效的 JSON | 文件内容坏了 |
| 这个名字的 JSON 不是对象 | 顶层是数组或数字，不是卡 |

## 出问题怎么查

### 启动卡在解包

第一次 60~90 秒正常，看百分比有没有在动。在动就等；长时间不动可能是磁盘满了，
清出 1 GB 再重启。

### 点角色没反应

正常应该立刻跳转，卡片内容后台慢慢加载。完全没反应就杀掉 App 重开。

### 聊天报"未配置 API"

去"我的 → API 连接"配一个。配完不用重启。

### 说话没反应

按顺序查：麦克风权限给了吗；"我的 → 语音输入配置"点测试连接通不通；
手机是不是正在微信语音通话（会占着麦克风）。

### 仓库连不上

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 提示证书错误 | 自建仓库用了自签证书 | 换正式证书，或先用浏览器信任一次 |
| 很快就失败 | 地址写错、端口没开 | 用浏览器试那个地址 |
| 等很久才失败 | 真的连不上 | 换网络试 |
| 灯是绿的下不了卡 | 未登录 | 先登录 |

失败得快（几百毫秒）通常是客户端问题，地址错或证书拒。失败得慢（十几秒）
才是网络问题。这个快慢本身是最省事的判断依据。

### 角色列表里有张"测试用-夜航小助手"

说明你装过 v0.1.7 早期版本。升到正式版后第一次启动会自动删掉。
文件名前缀和卡里的版本标记两条都命中才删，你自己建的卡不会被误删。

删的时候会给一句提示，不会静默动你目录里的文件。

## 明确做不到的事

这些不是 bug，是做或不做上的选择。

只支持 arm64。32 位老机型和 x86 设备（模拟器、云手机、少数 Chromebook）装不上。

不做卡片编辑器。只改场景、开场白、备用开场白三项。

不做 TXT 导入。PNG 卡和 JSON 卡能从手机里直接导进来（见上一节），
但 TXT 不行：桌面端的 TXT 是带板块标记的自有格式，手机上没有那套解析，
导进来只会得到一张空卡。

不做审计。平台规则校验、字数分布、问题定位都在桌面端。

自签证书要先信任。自建仓库用了自签证书的话，App 会拒绝连接，
系统的网络安全策略不允许 App 直接信任未知证书。三条出路：用正式证书
（Let's Encrypt 免费）、用反向代理终止 TLS 后填代理的域名、换内置云仓库。

聊天记录不能导出。要长期留就靠仓库里的卡加系统级备份。

语音识别靠第三方。App 不自带识别模型，那会让安装包再大几百 MB。
所有识别都调你配的那个服务，按那边计费。
