服务端已安装 · 如何连接

Tavern Card Studio Server — 本机部署。本页说明访问地址与访问令牌的获取方式。

1两个地址，分别用于不同用途

管理面板（在浏览器里打开，用于查看卡片、改配置、拿令牌）：

http://127.0.0.1:8731/

API（客户端填这个，不要填面板地址）：

http://127.0.0.1:8730

两个地址是独立配置的。把 API 改成 0.0.0.0 给局域网用时， 管理面板仍只监听本机（默认 127.0.0.1）——这是刻意设计：面板本身不带登录， 不应该出现在局域网上。如需远程运维，请单独修改「管理面板监听地址」并自建 TLS 反向代理。

2获取访问令牌

首次启动服务时，令牌会自动生成。首次取令牌用方式 1 或 2，之后可以在面板里随时查看。

  1. 配置文件（最快）：用记事本打开 C:\ProgramData\TavernCardStudio\config.json， 找 "token": "..." 这一行，引号里的内容就是令牌。
  2. 服务日志：打开 C:\ProgramData\TavernCardStudio\logs\， 找 tcs-service-host.out.log，搜索「访问令牌」—— 首次启动时会打印一次完整令牌。
  3. 管理面板（进得去之后最方便）：打开 http://127.0.0.1:8731/， 进入「API 与令牌」页即可看到完整令牌，旁边有复制按钮。 面板本身要输令牌才能进，所以首次需要先用上面两种方式取一次。
令牌是全权凭证。拿到令牌等于拥有服务端的全部操作权限， 请不要发到群里、截图外传或提交到代码仓库。

3在客户端里填好

  1. 打开 Tavern Card Studio 客户端，进入「设置」。
  2. 「服务端地址」填 http://127.0.0.1:8730（注意：是 8730，不是面板的 8731）。
  3. 「访问令牌」粘贴上面取到的令牌。
  4. 点「测试连接」，看到「已连接 · 令牌有效」即成功。

如果客户端与服务端装在同一台机器上，可以直接点「连接本机服务端」按钮， 它会自动探测并填好这两项。

4常见问题

现象处置
面板 127.0.0.1:8731 打不开 服务可能没启动。打开「服务」(services.msc)，看 Tavern Card Studio Server 的状态，不是「正在运行」就右键启动。
服务启动失败 / 一直是「正在启动」 看 C:\ProgramData\TavernCardStudio\logs\ 下的日志； 服务依赖 .NET Framework 4.x（Win10/11 自带）。
客户端提示「令牌无效」 重新从面板复制一次（注意别带多余空格）。若在面板里点过「轮换令牌」，旧令牌会立即失效。
改了端口后连不上 回面板「参数配置」页确认实际端口，客户端地址要跟着改。改完需要重启服务。

数据目录：C:\ProgramData\TavernCardStudio\　·　 卸载时该目录会保留（里面有卡片与版本历史）
