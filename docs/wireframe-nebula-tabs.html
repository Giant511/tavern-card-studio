这套线框要你确认的三件事

  • 暗夜优先、不做亮色主题 —— 是否接受
  • 强调色只出现在 5 个地方（当前 Tab / 生成光标 / 主行动文字 / 语音波形 / 空状态光晕），是否够克制
  • 聊天页是「角色列表 + 最近会话」两段，还是只留角色列表

刻意没做的

  • 没有骨架屏（大段文字流里会跳，改用呼吸点）
  • 没有满屏渐变按钮（只在文字上做渐变）
  • 列表项不用玻璃（性能：同屏玻璃层不超过 3 个）
  • 没有 emoji 图标，全部内联 SVG

触屏细节

  • 所有可点区 ≥ 44px，图标可以画得小但热区撑满
  • Tab 高 56px + 安全区，列表底部额外留 40px 防遮挡
  • 语音：按下浮起全屏浮层，松手发送、上滑取消
  • 未配置语音时麦克风置灰且点击弹引导，不是静默无响应
